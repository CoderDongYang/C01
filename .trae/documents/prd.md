## 1. 产品概述

CoDoc 是一个面向团队的实时协同文档编辑平台，支持多人同时编辑文档、AI 智能问答辅助、空间管理等功能。旨在解决团队协作中文档分散、版本混乱、沟通低效的痛点，为中小型团队提供轻量级但功能完备的协作写作体验。

- 目标用户：需要协同写作的研发团队、产品团队、内容创作团队
- 核心价值：实时协作 + AI 辅助写作，让团队知识沉淀更高效

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|---------|---------|
| 拥有者 (owner) | 创建空间时自动分配 | 空间全部管理权限，含删除空间、转让拥有者 |
| 管理员 (admin) | 由拥有者/管理员邀请或提升 | 管理成员、管理文档、生成邀请链接 |
| 成员 (member) | 通过邀请链接加入 | 查看、编辑空间内文档 |

### 2.2 功能模块

1. **认证页面**：用户注册、登录、JWT 鉴权
2. **空间仪表盘**：展示用户加入的空间列表、创建新空间、快速进入空间
3. **空间详情页**：空间内文档列表、成员列表展示、邀请链接生成、角色展示
4. **文档编辑器**：基于 TipTap 的富文本编辑器，支持基础格式化
5. **AI 对话面板**：侧边栏 AI 问答，基于 DeepSeek API

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 登录页 | 登录表单 | 邮箱 + 密码登录，表单验证，错误提示 |
| 注册页 | 注册表单 | 用户名 + 邮箱 + 密码注册，密码确认，表单验证 |
| 空间仪表盘 | 空间列表 | 展示用户加入的所有空间卡片，含空间名、成员数、文档数 |
| 空间仪表盘 | 创建空间 | 弹窗创建空间，输入空间名称和描述 |
| 空间详情页 | 文档列表 | 展示空间内文档，支持新建文档 |
| 空间详情页 | 成员列表 | 展示成员头像、名称、角色标签，支持邀请链接生成 |
| 文档编辑页 | TipTap 编辑器 | 富文本编辑，工具栏（加粗、斜体、标题、列表、代码块等） |
| 文档编辑页 | AI 对话面板 | 侧边栏，输入问题获取 AI 回答，支持流式输出 |

## 3. 核心流程

### 3.1 用户注册/登录流程
用户打开应用 → 未登录则跳转登录页 → 输入邮箱密码 → 后端验证 → 返回 JWT Token → 存储到 Zustand + localStorage → 跳转仪表盘

### 3.2 空间管理流程
用户在仪表盘 → 点击「创建空间」→ 输入名称描述 → 后端创建空间并自动添加为 owner → 返回空间列表 → 生成邀请链接 → 其他用户通过链接加入 → 选择角色

### 3.3 文档协作流程
用户进入空间 → 点击文档/新建文档 → 打开 TipTap 编辑器 → Socket.IO 实时同步 → AI 侧边栏辅助

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深靛蓝 (#1e1b4b) 作为品牌色，搭配翡翠绿 (#10b981) 作为强调色
- **次色调**：淡灰白 (#f8fafc) 背景，深灰 (#1e293b) 文字
- **按钮风格**：圆角按钮 (rounded-lg)，主按钮带微妙阴影和 hover 渐变效果
- **字体**：正文使用系统字体栈，标题使用 Geist Sans 风格
- **布局风格**：左侧导航栏 + 右侧内容区，卡片式布局
- **图标风格**：Lucide 图标库，线条风格，2px 描边

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|---------|---------|---------|
| 登录页 | 登录表单 | 居中卡片式布局，品牌 Logo 顶部，渐变背景，表单输入框带浮动标签，圆角主按钮 |
| 注册页 | 注册表单 | 同登录页风格，增加确认密码字段 |
| 空间仪表盘 | 空间列表 | 顶部导航栏，网格卡片布局，每张卡片含空间图标/名称/成员头像组/文档数量，hover 浮起效果 |
| 空间仪表盘 | 创建空间 | 居中弹窗 (Dialog)，表单含空间名称和描述输入 |
| 空间详情页 | 文档列表 | 左侧文档树/列表，右侧内容区，新建按钮突出显示 |
| 空间详情页 | 成员列表 | 右侧抽屉或面板，成员行含头像 + 名称 + 角色徽章，邀请链接区域 |
| 文档编辑页 | TipTap 编辑器 | 顶部工具栏，中间编辑区域白色卡片，左侧大纲导航 |
| 文档编辑页 | AI 对话面板 | 右侧可折叠侧边栏，对话气泡风格，流式输出打字机效果 |

### 4.3 响应式设计
- 桌面优先设计，最小宽度 1024px
- 平板适配：空间卡片从 3 列变 2 列，侧边栏可折叠
- 移动端：单列布局，底部导航替代侧边栏

### 4.4 动效设计
- 页面切换：淡入淡出 + 轻微上移 (fade-up)
- 卡片 hover：translateY(-2px) + box-shadow 增强
- 按钮 hover：背景色加深 + 微缩放 (scale 1.02)
- 加载状态：骨架屏 (skeleton) 替代 loading spinner
- AI 回复：打字机效果逐字输出
